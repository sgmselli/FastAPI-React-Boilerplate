# Features

What you get out of the box.

**Authentication** — Register and log in with email and password. JWT access and refresh tokens in httpOnly cookies, with automatic refresh and protected routes.

**Google OAuth** — Sign in with Google, linked by email to existing accounts. See [Google OAuth](google-oauth.md).

**Email delivery** — Transactional email through Brevo, sent on a Celery worker with retries. See [Email Delivery](email.md).

**File storage** — Upload, delete and serve files from S3-compatible object storage using presigned URLs. See [File Storage](file-storage.md).

**Google Analytics** — GA4 tag, ready for a measurement ID. See [Google Analytics](google-analytics.md).

**404 handling** — Catch-all route with a not-found page, and an SPA fallback so deep links survive a refresh.

**Legal pages** — Privacy policy and terms and conditions, routed and ready to fill in.

**Automated testing** — Unit, integration and end-to-end suites across backend and frontend. See [Automated Testing](automated-testing.md).

**Deployment built in** — Terraform for infrastructure, Ansible for provisioning, GitHub Actions for CI/CD. See [Deployment](deployment/index.md).

**Documentation** — Every one of the above, written up in this folder.
